Сброс и установка пароля:
1. При загрузке и далее выборе загрузки нажать букву "e";
2. Затем найти строку "linux /boot/vmlinuz .... ro quiet splash" и изменить ее в конце на "linux /boot/vmlinuz .... rw quiet splash init=/bin/bash";
3. Нажать Ctrl+x;
4. Загрузиться пользователь root@(none);
5. Ввести команду passwd имя_пользователя и ввести новый пароль.

sudo gvm-start - запуск
sudo gvm-check-setup - проверка статуса установки сервисов
sudo greenbone-feed-sync - обновление конфигураций
sudo runuser -u _gvm -- greenbone-nvt-sync - обновление сигнатур
-----------------------------------------------------------------------------------------------------------------------------
sudo vi /etc/fstab - откроем конфигурационный файл с помощью редактора vi (сохранить и выйти, нажать Esc, :wq)
Для того, чтобы защитить память, в конфигурационный файл вставляем строку none /run/shm/ tmpfs defaults, ro 0 0, но лучше использовать none /run/shm/ tmpfs rw,noexec.nosuid, nodev 0 0
ssh localhost - проверим установлен ли ssh (ssh: connect to host localhost port 22: Connection refused - значит сервер установлен)
sudo apt install gufw - установка брентмауэра

cat /etc/pam.d/sudo - конфигурационный файл для утилиты sudo
cat /etc/pam.d/common-auth - файл аутентификации
sudo apt install apparmor-utils apparmor-profiles - установка дополнительных компонентов к утилите AppArmor
sudo apparmor_status - выведет статус утилиты

dpkg --get-selections | grep -v deinstall > backup.txt - создание резервное копирование (создание списка установленных пакетов)
sudo dd if=/dev/sda2 of=~/backup.img - создание образа диска sda2
sudo tar cvpzf /media/sf_Linux//backup_pack.tgz --exclude=/backup.tar.gz --exclude=/home --exclude=/media --exclude=/dev --exclude=/mnt --exclude=/proc --exclude=/run --exclude=/sys / - создаст образ системы за исключением файл и каталогов указанных в exclude
tar xpf путь файл.tar - востанавливает все файлы из архива (x - обозначает извлечение файлов; p - сохранаяет права доступа; f - указывает на то, что следующим аргументом является имя архива или устройства)
