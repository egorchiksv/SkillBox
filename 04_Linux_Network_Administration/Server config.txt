Конфигурационный файл сервера лежат по пути /etc/netplan/ с расширением yaml.
В файле
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: true

* где:
version — версия YAML. На момент обновления статьи, была 2.
ethernets — настройка сетевых адаптеров ethernet.
enp0s3 — настройки для соответствующих сетевых адаптеров. В данном примере мы настраиваем 3 сетевых адаптера.
dhcp4 — будет ли получать сетевой адаптер IP-адрес автоматически. Возможны варианты yes/true — получать адрес автоматически; no/false — адрес должен быть назначен вручную.

В случае использовании конфигурации выше, будет автоматически настроены сетевые настроейки.

Просмотр названий установленных интерфейсов можно посмотреть с помощью команды ls /sys/class/net/.
Для настройки сетевых интерфейсов необходимо в файле с расширением yaml по пути /etc/netplan/ сделать следующую конфигурацию:
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: no
      addresses: [192.168.1.18/24]
      geteway4: 192.168.1.1
      nameserver:
	addresses: [1.1.1.1, 8.8.8.8]

Проверим конфигурацию с помощью команды sudo netplan --debug generate. Не должно быть ошибок.
С помощью команды sudo netplan --debug apply применим конфигурацию.
