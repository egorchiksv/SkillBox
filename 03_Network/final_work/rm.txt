show ip dhcp pool - показать все DHCP пулы

Создайте пул DHCP, дав ему произвольное имя, например MyPool (команда сразу переводит в режим настройки пула DHCP):
ip dhcp pool MyPool
Укажите сетевой адрес и маску подсети, в которой будут выдаваться адреса, например:
network 192.168.1.0 255.255.255.0
Укажите адрес шлюза по умолчанию (обычно это свой адрес, но не обязательно):
default-router 192.168.1.1
При необходимости укажите DNS-сервер:
dns-server 8.8.8.8
Для этого нужно выйти из настройки пула командой exit и указать диапазон IPv4-адресов для исключения из выдачи:
ip dhcp excluded-address 192.168.1.1 192.168.1.10
